# Motor Kurye, Müşteri ve Yönetici Platformu

Bu proje; motor kurye çağrıları, harita linki/adres ayrıştırma, dinamik KM/ücret hesaplama, durmaksızın çalan kurye alarmı ve PIN korumalı yönetici panelini içerir.

## GitHub Actions ile Otomatik APK Çıkarma
1. Bu projenin içeriğini GitHub deponuza yükleyin.
2. Üst menüdeki **Actions** sekmesine gidin.
3. **APK Uretici** iş akışının tamamlanmasını bekleyin.
4. Çıkan **KuryeUygulamasi-TamSurum-APK** paketini indirip Android telefonunuza kurun.
